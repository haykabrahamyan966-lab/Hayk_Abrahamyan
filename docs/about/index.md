# Մի փոքր իմ մասին

 Ես ծնվել և մեծացել եմ Գեղարքունիքի մարզում՝ Ճամբարակ քաղաքում։ 
 
 ![alt text](<../images/images (1).jpg>)

 
 Դիլիջանի կենտրոնական դպրոցում սովորում եմ 2025 թվականից,իսկ ՖաբԼաբ-ում՝ 2026։ Հետաքրքրվում եմ քիմիայով և ինժիներիայով, և ՖաբԼաբ-ը հնարավորություն կտա ինձ համատեղել այստեղ սովորած ինժիներական հմտությունները դպրոցում ձեռք բերածս գիտելիքներիս հետ՝ ապագայում իմ ընտրած մասնագիտությամ ճանապարհս շարունակելու համար։
